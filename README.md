# Movie Bot - Система управления списком фильмов

Telegram-бот для управления личной коллекцией фильмов и сериалов.

## 🎯 Функционал
- Авторизация пользователей с ролями (админ/пользователь)
- Поиск фильмов через Кинопоиск API
- Управление списком просмотренных/непросмотренных фильмов
- Случайный выбор фильма по жанру и типу
- Админ-панель для управления пользователями

## 🛠️ Технологии
- Python 3.11+
- Aiogram 3.x (Telegram Bot Framework)
- SQLAlchemy (async)
- PostgreSQL
- FastAPI (в процессе)

## 🚀 Быстрый старт
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Настроить `.env` файл
4. Запустить бота: `python -m bot.main`

## 📁 Структура проекта
```
movie_bot/
├── bot/ # Telegram бот
├── api/ # FastAPI слой (в разработке)
├── logs/ # Логи
└── .env # Конфигурация
```
## 🔧 Настройка
Создайте `.env` файл:
```env
BOT_TOKEN=ваш_токен_бота
DATABASE_URL=postgresql+asyncpg://user:pass@localhost/movie_bot
KINOPOISK_API_KEY=ваш_ключ_api
```
